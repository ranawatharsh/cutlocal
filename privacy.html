Privacy, in plain words

No accounts, no image uploads, no tracking scripts. This page exists so you can check the claim instead of trusting it.

What never leaves your device

Your images. All background removal happens inside the browser tab with WebAssembly. The file is read from disk into memory, the mask is computed locally, and the result is written back to disk by your browser's download mechanism. There is no endpoint that could accept an image, because the app has no backend at all — it is a set of static files.

What does get downloaded

  • The page itself: HTML, one CSS file and a small JavaScript bundle from this domain.
  • The AI engine, which starts downloading as soon as the page opens so it is ready when you are: the ONNX model (about 44 MB on the Fast setting) and the ONNX Runtime WebAssembly build (about 12 MB), served from staticimgly.com. It is cached, so this happens once.
  • Nothing else. There is no font CDN, no analytics script, no ad network, no pixel.

If you are on a metered connection, turn on your browser's Save-Data setting (or Lite mode) and the download will wait until you press "Load AI now" or add an image.

What is stored on your device

  • localStorage — your export preferences (format, quality, size preset, padding, chosen model). A few hundred bytes, and only if you change something.
  • HTTP cache and Cache Storage — the model files, so the next visit starts instantly and works offline.
  • Nothing else. No cookies, no identifiers, no fingerprinting.

How to verify it in 20 seconds

Open DevTools (F12 or Cmd ⌥ I), go to the Network tab, then drop an image onto the tool. You will see the model request the first time, and nothing at all while the image is processed. No request carries your file. If that is ever not true, it is a bug — please report it.

You can also disconnect from the internet after the model has loaded and keep working: the app is served by a service worker and the model is cached.

Why this design

Server-side background removal has a cost per image, which is why most services cap usage, add watermarks or require an account. Running the model on the visitor's machine removes that cost entirely — and, as a side effect, removes the need to collect anything at all. Local processing is both the privacy story and the business model.

Third parties

Model files are hosted by IMG.LY (staticimgly.com), the authors of the open-source engine. That request reveals your IP address and the model file you asked for, in the same way any CDN request does. It contains no image data. If you would rather avoid it entirely, the engine can be self-hosted — see the project documentation.
