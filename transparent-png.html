Transparency, explained in one paragraph

A transparent image stores a fourth value per pixel — alpha — that says how opaque it is. JPEG has no alpha channel at all, which is why "transparent JPEG" is a contradiction and why a JPEG export of a cutout always comes out on a solid colour. PNG supports full 8-bit alpha, WebP supports it too, and both are handled natively by every modern browser, Figma, Canva, Illustrator and Photoshop.

Two things are worth knowing before you export:

  • Edges are anti-aliased. A good cutout has semi-transparent pixels at the border, which is what stops it looking like a paper cut-out. Don't run a hard threshold on it afterwards.
  • File size is dominated by the photo. A 4000 px cutout is heavy in PNG. For web use, resize to the longest side you actually need — 1024 or 2048 px is usually plenty — and export WebP.

If you are preparing assets for a dark UI, check the result on a dark background as well as the checkerboard: light halos from the original background are much easier to spot there.

Questions people ask

How do I make a PNG with a transparent background?

Drop the image here. The AI separates the subject from the background and returns an image with an alpha channel, which is then exported as PNG. Keep the format set to PNG — JPEG cannot store transparency, so any transparent area becomes white.

Does it work on logos and signatures?

It works best on logos and signatures that sit on a plain, even background — a white page, a solid colour. The model is trained on photographic subjects, so a flat logo with sharp vector edges can come back slightly softened. For clean line art, a magic-wand style tool is often better; for photos, stickers and product shots this tool is the right one.

Why is my PNG so much larger than the JPEG?

PNG is lossless, so it stores every pixel exactly. A photographic cutout can be several megabytes. Switch the export format to WebP to keep transparency at roughly a third of the size — it is supported by every current browser and by Figma, Canva and Photoshop.

Is there a watermark or a size limit?

No watermark, no resolution limit beyond your browser's canvas limits, and no per-day cap. The tool is a static page: there is no server to meter you.
